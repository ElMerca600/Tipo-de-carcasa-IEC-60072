
# ⚙️ Tipo de carcasa de motores según IEC 60072-1

## 📌 Descripción
Herramienta para identificar tipos de carcasa y dimensiones de motores eléctricos de baja tensión según la norma IEC 60072-1.

## 🎯 Objetivo
Facilitar la selección y verificación de motores en tareas de:
- mantenimiento
- reemplazo
- montaje en campo

## 🧠 Alcance
Esta aplicación permite:
- Identificar tipos de carcasa de motores
- Consultar dimensiones normalizadas
- Comprender la clasificación de motores según norma IEC

## 🧠 Normativa aplicada
- IEC 60072
- Clasificación de dimensiones y tamaños de motores eléctricos

## 🚀 Uso
1. Abrir el archivo `index.html`
2. Seleccionar el tipo de motor o carcasa
3. Consultar dimensiones y características correspondientes

## 🛠 Tecnologías
- HTML
- CSS
- JavaScript
